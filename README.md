# FAF-HD_Dataset
The paper of FAF-HD: A Feature Adaptive Fusion Framework for Heterogeneous Data toward Person-Independent RFID Indoor Fingerprint Localization 's dataset. The dataset is publicly available in the Releases repository.
The "FAF-HD dataset-8 people" is an expansion of the previous "FAF-HD dataset", with the number of participants increasing from 4 to 8. The label consists of two parts: [Position ID, Personnel ID]
